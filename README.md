# Basic Calculator (HTML + JavaScript)

This project is a simple web-based calculator built using HTML and JavaScript.
It supports basic arithmetic operations along with selected trigonometric functions.

## Features

* Addition, Subtraction, Multiplication, Division
* Trigonometric calculations (`sin`, `cos`, etc.)
* Interactive button-based interface
* Instant result display
* History of calculations

## Technologies Used

* HTML
* JavaScript
* CSS (for styling)

## Purpose

This project was developed as a learning exercise to practice JavaScript logic, DOM manipulation, and building interactive web interfaces.
